# 갤러리 카드 대시보드

gallery-card-engine의 설정을 팝업에서 실시간으로 미리 보고, 출력 코드를 만드는 콘솔용 도구입니다.

## 필요한 것

- gallery-card-engine.js v2.2.0 이상 (`GA.dashboard` API)
- PC 브라우저, 팝업 허용

## 사용 방법

1. 갤러리가 있는 페이지를 열고 콘솔에 `gallery-card-dashboard.js` 전체를 붙여 넣어 실행합니다.
2. 값을 바꾸면 화면에 바로 반영됩니다.
3. 최종적용 코드 출력하기로 `window.GA_USER` 코드를 복사해 우피의 설정 블록에 붙여 넣습니다.

팝업을 닫아도 임시 편집은 화면에 남습니다. 새로고침하거나 무효화하면 시작 상태로 돌아갑니다. 노션과 GitHub에는 아무것도 쓰지 않습니다.

## 우선순위

대시보드 임시 편집 > 페이지의 `window.GA_USER` > 엔진 기본값

## 설정 그룹

| 그룹 | 내용 |
|---|---|
| 그리드·정렬 | PC·태블릿·모바일 열 수, 카드 간격, 상자·텍스트 정렬 |
| 카드 | 배경, 테두리, 모서리, 그림자 빌더 |
| 호버 효과 | 전체·배경·그림자·떠오름·이미지 확대·제목 색을 각각 켜고 끄기 |
| 썸네일 | 비율, 안쪽 여백, 모서리, 채움 방식 |
| 메인 태그 | 표시 방식, 선택 값 순번, 색, 위치, 크기 |
| 본문·타이포 | 본문 여백, 제목·설명·메타 글자, 프로필 이미지 |
| 작성자·날짜 줄 배치 | 자동/항상 두 줄/항상 한 줄, 날짜 줄이기, 두 줄일 때 날짜 정렬과 간격 |
| 속성 사이 세로 간격 | 블록 사이, 제목·설명·메타 아래, 추가 속성 묶음 사이 |
| 날짜 표기 | 형식, 요일, 시간, 12/24시간, 기간 구분 기호, 날짜·요일·시간 글자 크기와 굵기 |
| 추가 속성·선택 알약 | 묶음, 나열 방향, 간격, 알약 색과 크기 |
| 기타 관계형 속성 | 아이콘만 있는 그 밖의 속성 스타일 |
| 탭·제목별 규칙 | 탭이나 갤러리 제목별 태그 예외 |

## 그림자 빌더

프리셋 칩(없음, 은은, 보통, 강함, 테두리 링, 노션 기본)을 고르거나 가로·세로·흐림·퍼짐 슬라이더, 색과 투명도, 안쪽 그림자(inset), 1px 테두리 링으로 조절합니다. 위쪽 미리보기 상자에서 결과를 확인할 수 있으며, 직접 입력(고급)에서 CSS 값을 바로 쓸 수도 있습니다.

## 호버 효과

호버 시 배경색, 그림자, 떠오름, 이미지 확대, 제목 색을 각각 켜고 끌 수 있고 전체 스위치로 한꺼번에 끌 수 있습니다. 호버 그림자의 기본값은 투명이므로, 호버 시 그림자를 보려면 호버 그림자를 설정해야 합니다.

## 작성자·날짜 줄 배치

| 방식 | 동작 |
|---|---|
| 자동 | 한 줄에 들어가면 이름 왼쪽·날짜 오른쪽. 넘치면 날짜를 먼저 줄이고(요일·시간 생략 → 짧은 형식), 그래도 넘치면 두 줄(이름 위, 날짜 아래) |
| 항상 두 줄 | 모든 카드가 이름 위, 날짜 아래 |
| 항상 한 줄 | 날짜를 고정하고 이름이 길면 말줄임(…) |

날짜 형식이 원본 그대로이면 날짜 줄이기가 동작하지 않고 바로 두 줄이 됩니다. 두 줄인 카드는 한 줄 카드보다 높으므로, 높이를 통일하려면 항상 두 줄을 사용합니다.

## 기능

- 되돌리기/다시 실행 (최대 100단계), 원본 복원, 눈 버튼(누르는 동안 시작 상태), 무효화, 항목별 ↺
- 임시저장 슬롯 (최대 30개), 스타일 프리셋
- 가져오기: `window.GA_USER={...}`, `:root` CSS 변수, 이 대시보드가 내보낸 JSON
- 설정 검색, 다크/라이트, 최소화
- 페이지 클릭 선택: 켜 두면 카드를 클릭해 해석 결과를 보고 링크 이동을 막습니다.

## 카드 점검

카드 목록과 선택한 카드의 해석 결과(제목, 커버 이미지, 태그, 선택 값, 설명, 날짜, 작성자/관계형, 작성자·날짜 줄 배치, 텍스트, 기타 아이콘 속성)를 보여 줍니다. 디자인이 적용되지 않는 카드가 있으면 이 화면의 ⚠와 해석 결과를 먼저 확인합니다.

## 출력

- 기본값과 다른 항목만 `window.GA_USER`로 출력합니다. "전체 설정 출력"을 켜면 모든 항목을 출력합니다.
- 복사하기, 미니파이 복사를 지원하며 출력 항목 수와 글자 수를 보여 줍니다.
- 기존 설정 블록(또는 예전 `:root` 변수 블록, `GA_CONFIG`)을 출력 코드로 교체합니다.

## 설정 점검

시험값을 넣어 설정이 엔진에 반영되는지 확인하고 원래대로 되돌립니다. 결과는 항목마다 적용/실패로 표시됩니다. 눈에 보이는지는 직접 확인해야 합니다.

## 저장소 키

`gallery-dashboard-v1-preferences`, `gallery-dashboard-v1-slots`, `gallery-dashboard-v1-presets`

## 알려진 제한

- PC 전용이며 팝업이 차단되면 실행되지 않습니다.
- 대시보드에서 PC·태블릿·모바일 열 수는 팝업이 아니라 실제 페이지 창 너비 기준으로 적용됩니다.
- 노션의 속성 값 자체는 노션에서 수정합니다. 이 대시보드는 표시 설정만 편집합니다.
- 실제 우피 페이지에서의 동작은 직접 확인해야 합니다.
