# code-badge 대시보드

code-badge의 설정을 팝업에서 편집하고 출력 코드를 만드는 콘솔용 도구입니다.

## 필요한 것

- code-badge.js v1.7.0 이상 (`__ecbApi_q4m.dashboard` API 1.0.0, `declare` 포함)
- PC 브라우저, 팝업 허용

## 사용 방법

1. 페이지를 열고 콘솔에 `code-badge-dashboard.js` 전체를 붙여 넣어 실행합니다.
2. 편집 범위를 고릅니다. 뱃지는 목록에서 고르거나 페이지의 뱃지를 클릭해서 고릅니다.
3. 값을 바꾸면 화면에 바로 반영됩니다.
4. 최종적용 코드 출력하기로 `<script>` 블록을 복사해 우피에 붙여 넣습니다.

팝업을 닫아도 임시 편집은 화면에 남습니다. 새로고침하거나 무효화하면 시작 상태로 돌아갑니다. 콘솔 기록 용량이 부족하면 오류가 날 수 있으니, 실행 전에 콘솔 기록을 비우는 것을 권합니다.

## 편집 범위

| 범위 | 대상 | 출력 |
|---|---|---|
| 사이트 공통 | 모든 뱃지 | `window.ecbConfig_q4m` |
| 뱃지 | 뱃지 하나(`블록ID:순번`). "개별 지정"을 켠 항목만 출력 | `window.ecbItems_q4m` |

우선순위는 대시보드 임시 편집 > 개별 > 공통 > 엔진 기본값입니다.

## 개별 지정이 공통값보다 우선합니다

개별 지정된 항목은 사이트 공통 편집이 적용되지 않습니다. 공통 모드에서 항목 아래에 개별 지정 중인 뱃지가 표시되고, "개별 지정 해제하고 공통값 확인" 버튼으로 임시로 풀어서 볼 수 있습니다. 우피에 선언된 값은 바뀌지 않습니다.

뱃지 모드에서 "개별 지정"을 끄면 그 항목은 개별 설정에서 빠지고 공통값을 보여 줍니다.

## 표시 조건

- 테두리 항목은 스타일이 아웃라인 또는 채움+테두리일 때만 보입니다.
- 링크 밑줄과 링크 글자 투명도는 링크 뱃지에서만 보입니다.
- 링크 뱃지 사용, 디버그 로그는 공통 모드에서만 바꿉니다.
- "뱃지 사용"은 공통에서는 전체, 뱃지 모드에서는 이 뱃지입니다.

## 기능

- 되돌리기/다시 실행(최대 100단계), 원본 복원, 눈 버튼(누르는 동안 시작 상태), 무효화, 항목별 ↺
- 임시저장 슬롯(최대 30개), 스타일 프리셋
- 가져오기: 내보낸 `<script>` 블록 또는 이 대시보드가 내보낸 JSON. "가져오기 전에 임시 편집 초기화"를 켜면 선언값에서 시작해 적용합니다.
- 설정 검색, 다크/라이트, 최소화, 모두 펼치기/접기
- 페이지 클릭 선택: 켜 두면 뱃지를 클릭해서 대상을 고르고 링크 이동을 막습니다. Esc로 끌 수 있습니다.
- 이 페이지에 없는 개별 설정을 따로 보여 주고 삭제할 수 있습니다. 다른 페이지의 설정일 수 있으니 확인 후 삭제하세요.

## 출력

- 최종 `<script>` 블록: 두 설정과 `declare(...)` 호출을 합친 코드입니다. 우피의 기존 code-badge 설정 블록을 이것으로 교체합니다.
- "전체 설정 출력"을 켜면 기본값과 같은 항목도 모두 출력합니다.
- 복사하기, 미니파이 복사(주석 제거, 한 줄 JSON)를 지원합니다.

## 설정 점검

시험값을 넣어 공통, 뱃지 편집이 엔진과 화면 변수에 반영되는지 확인하고 원래대로 되돌립니다. 항목마다 적용 또는 실패로 표시됩니다. 눈에 보이는지는 직접 확인해야 합니다. 공통 점검에서 "뱃지 사용"은 전체가 꺼지므로 시험하지 않습니다.

## 저장소 키

`code-badge-dashboard-v1-preferences`, `code-badge-dashboard-v1-slots`, `code-badge-dashboard-v1-presets`

## 알려진 제한

- 글자색과 배경색은 노션에서 수정합니다. 이 대시보드는 모양만 편집합니다.
- 개별 설정은 `블록ID:순번` 키라서 블록을 복제하거나 지우면 끊어질 수 있습니다.
- 팝업이 차단되면 실행되지 않으며 PC 전용입니다.
- 실제 노션 화면에서의 동작은 직접 확인해야 합니다.
