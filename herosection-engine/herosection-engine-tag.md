# 히어로 섹션 — 노션 속성 참고표 (v2)

## 그룹(섹션) 이름 규칙

| 그룹 이름 | 역할 |
|---|---|
| `[% 섹션 1 :: hero %]`, `[% 섹션 2 :: hero %]`, ... | 슬라이드 하나씩. 메인타이틀이 채워진 그룹이 2개 이상이면 자동으로 전체 슬라이드 캐러셀 |
| `[% 전체관리 :: hero %]` | 개별 슬라이드가 아닌, 히어로 전체에 적용되는 설정 |

## "섹션 N" 그룹 안에 넣는 속성

| 속성명 | 노션 속성 유형 | 값 형식 / 예시 | 필수 | 여러 개 |
|---|---|---|---|---|
| `메인타이틀 N` | 텍스트 | Shift+Enter 줄바꿈 가능 | **필수** | 1개 |
| `서브타이틀 N-M` | 텍스트 | Shift+Enter 줄바꿈 가능 | 선택 | 예 |
| `버튼 N-M` | 텍스트(링크 삽입) | 아래 "버튼 태그" 참고 | 선택 | 예 |
| `배경이미지 N-M` | 파일과 미디어 | 이미지 업로드(여러 장이면 자동 순환) | 선택 | 예 |
| `배경이미지(모바일) N-M` | 파일과 미디어 | 모바일 화면일 때만 사용 | 선택 | 예 |
| `배경영상URL N` | URL | 유튜브 / 비메오 / mp4 직접 링크 / 픽사베이·펙셀 다운로드 링크 | 선택(이미지보다 우선) | 1개 |
| `배경색 N` | 텍스트 | `#1a1a1a`, `1a1a1a`, `rgba(0,0,0,1)`, `0,0,0,1` 전부 인식 | 선택 | 1개 |
| `배경위치 N` | Select | `상단` / `중앙` / `하단` | 선택(기본 중앙) | 1개 |
| `배경배율 N` | 텍스트(숫자) | `100`(기본) / `120` | 선택 | 1개 |
| `가로정렬 N` | Select | `좌측` / `중앙` / `우측` | 선택(기본 중앙) | 1개 |
| `세로정렬 N` | Select | `상단` / `중앙` / `하단` | 선택(기본 중앙) | 1개 |
| `쉐도우색상 N` | 텍스트 | 색상 형식 동일(위 배경색 참고) | 선택(비우면 대시보드 기본값) | 1개 |
| `쉐도우투명도 N` | 텍스트(숫자, 0~100) | `40` | 선택(색상과 함께 있을 때만 적용) | 1개 |
| `노출시간 N` | 텍스트(숫자, 초) | `6` | 선택 | 1개 |

## "전체관리" 그룹 안에 넣는 속성

| 속성명 | 노션 속성 유형 | 값 형식 / 예시 | 필수 |
|---|---|---|---|
| `용도` | Select | `메인 Main` / `서브 Sub` | 필수(없으면 메인으로 처리) |
| `높이` | Select | `전체화면 100vh \| 1920×1080~2400×1350`, `크게 70vh \| 1920×900`, `보통 50vh \| 1920×700`, `배너 30vh \| 1920×500`, 또는 직접 `35vh` 같은 옵션 추가 | 선택 |
| `넓이` | Select | `가득 채우기 Full` / `본문 너비 Fit` | 선택 |

## 버튼 태그 (버튼 값 텍스트 끝에 붙임)

```
[% ST 스타일 :: IC 아이콘 :: Ga 간격 :: hero | button %]
```

- `ST`(또는 `Style`) — `line`(테두리형/outline) 또는 `full`(채워짐/solid). 생략하면 첫 버튼은 자동 full, 나머지는 자동 line.
- `IC`(또는 `Icon`) — 폰트어썸 클래스. `fa-solid fa-arrow-right`처럼 클래스명만 써도 되고, 폰트어썸 사이트에서 복사한 `<i class="...">` 전체를 그대로 붙여도 인식됩니다.
- `Ga`(또는 `Gap`) — 이 버튼 뒤에 넣을 간격(칸 수, 0.1 단위 가능).
- 대소문자 구분 없음, 순서 상관없음, 세 개 다 안 써도 되고 필요한 것만 넣으면 됩니다.
- 맨 끝 `hero | button`은 고정 문구입니다 — 반드시 그대로 붙여야 인식됩니다.

**예시**: `Contact Us [% ST full :: IC fa-solid fa-play :: Ga 1.5 :: hero | button %]`

## 제목/부제 간격 태그 (버튼이 아닌 곳에서 단독으로 쓸 때)

```
[% gap :: 1.5 %]
```
메인타이틀·서브타이틀 값 끝에 붙이면 그 항목 바로 다음에 간격이 생깁니다.

## 오류 확인 방법

속성명·값·태그가 잘못 입력되면 화면에는 표시되지 않고(방문자가 어색한 화면을 보지 않도록), **브라우저 개발자 콘솔에 `[히어로엔진]`으로 시작하는 경고 메시지**가 남습니다. 테스트할 때는 콘솔을 열어서 확인해주세요.

## 안정성 관련

노션 내부 클래스명이 바뀌어서 평소 방식으로 속성 패널을 못 찾더라도, `[% ... :: hero %]` 텍스트 자체를 페이지에서 직접 찾아 숨기는 백업 로직이 있어 방문자에게 원본 속성 패널이 노출되는 상황은 방지됩니다(이 경우 콘솔에 관련 경고가 남습니다).
