# db-tabs 사용 설명서

Notion/Oopy로 만든 사이트에서, 데이터베이스(갤러리·표 등) 위에 붙는 "탭(뷰 전환)" 영역을
CSS에 의존하지 않고 커스터마이징하기 위한 코드 모음입니다. Notion이 자체 CSS
클래스명을 언제든 바꿀 수 있기 때문에, 이 코드는 클래스명이 아니라 `role`,
`data-block-id` 같은 안정적인 속성을 기준으로 탭을 찾아 스타일을 적용합니다.

## 파일 구성

| 파일 | 역할 | 사이트에 항상 필요한가 |
|---|---|---|
| `db-tabs-engine.js` | 실제 DOM을 찾아 스타일/동작을 적용하는 로직 (고정, 거의 안 바꿈) | 필요 |
| `db-tabs-option` | 색상·크기·여백·동작 방식 등 실제 값 (자주 바꾸는 부분) | 필요 |
| `db-tabs-all` | 위 두 파일을 하나로 합쳐놓은 파일 (편의용) | 선택 |
| `db-tabs-dashboard.js` | 값을 슬라이더/색상선택 UI로 편하게 조정하는 제어판 실행기 | 운영자만 필요 시 실행 |
| `db-tabs-howto.md` | 이 문서 | - |

## 기본 개념

- **엔진(로직)과 옵션(값)은 분리되어 있습니다.** 디자인을 바꿀 때는 `db-tabs-option`의
  값만 수정하면 되고, `db-tabs-engine.js`는 건드릴 필요가 없습니다.
- 모든 변수명 끝에는 `_q9X`라는 접미사가 붙어 있습니다. 다른 커스텀 코드와 이름이
  겹치는 것을 막기 위한 식별 꼬리표이며, 엔진과 옵션 파일 사이에 반드시 동일해야
  합니다. **임의로 바꾸지 마세요.**
- 값은 두 종류로 나뉩니다.
  - CSS 변수(`:root { --xxx_q9X: 값; }`): 색상, 크기, 여백처럼 "생김새"를 정함.
  - `window.tabDbSetting_q9X` 객체: 오버플로우 처리 방식, 제목/탭줄 노출 여부처럼
    "동작 방식"을 정함. 데이터베이스별로 다르게 지정할 수 있음(아래 참고).

## 설치 방법

1. Notion 임베드/코드 블록, 또는 Oopy 커스텀 코드 삽입 영역에 `db-tabs-engine.js`
   내용을 넣습니다.
2. 같은 방식으로 `db-tabs-option` 내용을 넣습니다. (순서는 상관없지만 둘 다
   페이지에 있어야 합니다)
3. 페이지를 새로고침하면 탭에 옵션 파일의 값이 적용됩니다.

## 값 조정 방법 (두 가지)

### 방법 A. 직접 텍스트 수정
`db-tabs-option` 안의 값을 원하는 대로 바꿔서 다시 붙여넣습니다. 각 변수 위에
주석으로 기능·기본값·입력 가능한 값이 적혀 있으니 참고하세요.

### 방법 B. 제어판(대시보드) 사용
1. `db-tabs-dashboard.js`를 실행하면 팝업 창으로 제어판이 뜹니다. (관리자만 접근
   가능하도록 별도 버튼이나 북마클릿으로 연결해서 사용하세요)
2. 팝업에서 슬라이더, 색상 선택, 토글 등을 조작하면 **실제 사이트 화면에 바로
   반영되어 미리 볼 수 있습니다.**
3. 마음에 드는 값이 나오면 맨 아래 "최종 적용 코드 출력하기"를 누르고, 나온
   코드를 복사해서 `db-tabs-option` 자리에 통째로 교체합니다.

제어판에는 검색창, 다크/라이트 모드, localStorage 임시저장(여러 슬롯 관리),
이전 출력 코드 불러오기(가져오기), 항목별/전체 초기화, 데이터베이스별 설정 표
(추가/복제/삭제) 기능이 포함되어 있습니다.

## 데이터베이스별로 다르게 설정하기 (라벨 vs blockId)

사이트에 데이터베이스가 여러 개 있을 때, 전부 같은 디자인을 쓰고 싶다면 손댈 게
없습니다. 특정 데이터베이스 하나만 다르게 하고 싶을 때는 `db-tabs-option` 맨 아래
`window.tabDbSetting_q9X.exceptions` 배열에 항목을 추가합니다.

- **제목이 화면에 보이는 데이터베이스** → `label`에 그 제목 텍스트를 정확히
  입력합니다.
- **제목을 Notion에서 비노출로 꺼둔 데이터베이스** → 텍스트 자체가 없으므로
  `label`을 쓸 수 없습니다. 대신 `blockId`를 사용해야 합니다. blockId는 Notion에서
  해당 데이터베이스 블록을 우클릭 → 링크 복사로 얻은 주소 끝부분의 문자열입니다.
- 같은 이름의 데이터베이스가 두 개 이상이라 label로 구분이 안 될 때도 `blockId`를
  사용하세요.

하나의 예외 객체 안에는 `titleVisible`, `tabVisible`, `mode` 등 바꾸고 싶은
항목을 원하는 만큼 같이 적으면 됩니다. (항목이 여러 개라고 객체를 여러 개로
나눌 필요 없습니다)

## 자주 발생하는 문제와 대처법

**Q. 코드를 넣었는데 탭 디자인이 하나도 안 바뀐다**
- `db-tabs-engine.js`와 `db-tabs-option`이 둘 다 실제로 삽입되어 있는지 확인.
- 두 파일의 변수 접미사(`_q9X`)가 서로 같은지 확인. (하나를 임의로 바꾸면 안 됨)
- 브라우저 콘솔(F12)에서 에러 메시지가 뜨는지 확인.

**Q. 특정 데이터베이스만 설정이 적용 안 된다**
- 그 데이터베이스의 제목이 Notion에서 노출 상태인지 비노출 상태인지 먼저 확인.
  노출 상태인데 `label`이 안 먹으면 제목 텍스트에 오타나 앞뒤 공백이 없는지 확인.
  비노출 상태라면 `label`이 아니라 반드시 `blockId`를 써야 합니다.
- 같은 이름의 데이터베이스가 여러 개 있어서 라벨이 겹치는 건 아닌지 확인.

**Q. 탭이 많아졌을 때 화면이 이상하게 보인다 (줄바꿈/더보기/스크롤)**
- `mode`(또는 데이터베이스별 예외의 mode)가 원하는 값으로 설정되어 있는지 확인.
- 모바일에서만 다르게 보이길 원한다면 `mobileMode`를 채웠는지 확인. (`null`이면
  PC와 동일하게 동작함)

**Q. 활성 탭 밑에 원치 않는 밑줄이 보인다**
- Notion이 활성 탭에 기본으로 얇은 밑줄을 그리는데, 엔진이 이를 항상 제거하고
  `--activeUnderlineToggle_q9X` 값에 따라 켜고 끕니다. 이 값이 `0`이면 밑줄이
  완전히 사라지고, `1`이면 `--activeUnderlineSize_q9X`(두께)와
  `--activeUnderlineColor_q9X`(색상) 값대로 다시 그려집니다.

**Q. 제목이나 탭 줄을 화면에서만 숨기고 싶다 (Notion 설정은 그대로 두고 싶다)**
- `titleVisible: false` / `tabVisible: false`를 사용하세요. Notion 자체의
  "제목 비노출" 기능을 쓰면 라벨 텍스트 자체가 사라져서 나중에 예외 지정이 안
  되니, 화면에서만 숨기고 싶다면 Notion 설정은 "노출"로 둔 채 이 옵션을 쓰는
  것이 좋습니다.

**Q. 대시보드(제어판)에서 바꾼 값이 저장이 안 된 것 같다**
- 대시보드는 팝업을 닫으면 그동안의 조정 내역이 사라집니다. 값을 확정했다면
  반드시 "최종 적용 코드 출력하기"로 코드를 뽑아 `db-tabs-option`에 반영하거나,
  최소한 "임시저장(새 슬롯)"으로 localStorage에 저장해두세요.

**Q. 색상 코드를 입력했는데 안 먹는다**
- `#hex`(`#fff`, `#ffffff`) 또는 `rgba(r,g,b,a)` 형식, `transparent`만 인식됩니다.
  다른 형식(색상 이름 등)은 오류로 처리되어 적용되지 않습니다.
