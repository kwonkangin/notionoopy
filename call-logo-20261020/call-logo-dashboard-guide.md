# call-logo 대시보드

call-logo의 설정을 팝업에서 미리 보고 출력 코드를 만드는 콘솔용 도구입니다.

## 필요한 것

- call-logo.js v1.4.0 이상 (CallLogoEngine.dashboard API 1.0.0, `scopes.release` 포함)
- PC 브라우저, 팝업 허용

## 사용 방법

1. 페이지를 열고 콘솔에 `call-logo-dashboard.js` 전체를 붙여 넣어 실행합니다.
2. 편집 범위를 고릅니다. 카드는 목록에서 고르거나 페이지의 슬라이더를 클릭해서 고릅니다.
3. 값을 바꾸면 화면에 바로 반영됩니다.
4. 최종적용 코드 출력하기로 CSS와 카드 토큰을 복사해 노션에 붙여 넣습니다.

팝업을 닫아도 임시 편집은 화면에 남습니다. 새로고침하거나 무효화하면 시작 상태로 돌아갑니다.

## 편집 범위

| 범위 | 대상 | 출력 |
|---|---|---|
| 사이트 공통 | :root CSS 변수. 가로 간격, 세로 간격, 속도, 이미지 크기 | CSS 블록 |
| 카드 | 콜아웃 하나의 토큰. "개별 지정"을 켠 항목만 출력 | `[% call-logo :: ... %]` |

우선순위는 대시보드 임시 편집 > 토큰 > 사이트 공통 CSS > 엔진 기본값입니다.

## 개별 지정이 공통값보다 우선합니다

토큰에 적힌 항목은 사이트 공통 편집이 적용되지 않습니다. 사이트 공통 편집에서 해당 카드가 항목 아래에 표시되고, "개별 지정 해제하고 공통값 확인" 버튼으로 임시로 풀어서 볼 수 있습니다. 노션 원문은 바뀌지 않습니다.

카드 편집에서 "개별 지정"을 끄면 그 항목은 토큰에서 빠지고 공통값이나 기본값을 보여 줍니다.

## 표시 조건

- 세로 간격은 줄 수가 2일 때만 보입니다.
- 캡션 크기·색은 캡션이 있는 카드에서만 보입니다.
- 공통 모드에서는 공통 CSS 변수가 있는 4개 항목만 보입니다.

## 기능

- 되돌리기/다시 실행 (최대 100단계), 원본 복원, 눈 버튼(누르는 동안 시작 상태), 무효화, 항목별 ↺
- 임시저장 슬롯 (최대 30개), 스타일 프리셋
- 가져오기: 공통 :root CSS 또는 이 대시보드가 내보낸 JSON
- 설정 검색, 다크/라이트, 최소화
- 페이지 클릭 선택: 켜 두면 슬라이더를 클릭해서 카드를 고르고 링크 이동을 막습니다.

## 출력

- 출력 키 이름을 정식 이름(GAPX, HOVER_PAUSE) 또는 별칭(HP, CS) 중에서 고를 수 있습니다.
- "전체 설정 출력"을 켜면 기본값과 같은 항목도 모두 출력합니다.
- 복사하기, 미니파이 복사(주석 제거)를 지원합니다.
- 변경한 카드가 여러 개이면 제목·ID와 함께 목록으로 출력합니다.

## 설정 점검

시험값을 넣어 공통, 카드 편집이 엔진에 반영되는지 확인하고 원래대로 되돌립니다. 결과는 항목마다 "적용 / 개별 지정 우선 / 실패"로 표시됩니다. 개별 지정 우선은 정상 동작입니다. 눈에 보이는지는 직접 확인해야 합니다.

## 저장소 키

`call-logo-dashboard-v1-preferences`, `call-logo-dashboard-v1-slots`, `call-logo-dashboard-v1-presets`

## 알려진 제한

- 로고 이미지와 캡션 글자는 노션에서 수정합니다.
- 노션 원문의 토큰은 엔진이 읽은 값 기준이므로, 노션에서 토큰을 고친 뒤에는 새로고침합니다.
- 팝업이 차단되면 실행되지 않으며 PC 전용입니다.
- 실제 노션 화면에서의 동작은 직접 확인해야 합니다.
