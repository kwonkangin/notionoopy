# call-cta 대시보드

call-cta의 설정을 팝업에서 미리 보고 출력 코드를 만드는 콘솔용 도구입니다.

## 필요한 것

- call-cta.js v1.1.0 이상 (CallCtaEngine.dashboard API 1.0.0, scopes.release 포함)
- PC 브라우저, 팝업 허용

## 사용 방법

1. 페이지를 열고 콘솔에 call-cta-dashboard.js 전체를 붙여 넣어 실행합니다.
2. 편집 범위를 고릅니다. 카드는 목록에서 고르거나 페이지의 콜아웃을 클릭해서 고릅니다.
3. 값을 바꾸면 화면에 바로 반영됩니다.
4. 최종적용 코드 출력하기로 CSS와 카드 토큰을 복사해 노션에 붙여 넣습니다.

팝업을 닫아도 임시 편집은 화면에 남습니다. 새로고침하거나 무효화하면 시작 상태로 돌아갑니다.

## 편집 범위

| 범위 | 대상 | 출력 |
|---|---|---|
| 사이트 공통 | :root CSS 변수 37개 전체 | CSS 블록 |
| 카드 | 콜아웃 하나의 토큰. '개별 지정'을 켠 항목만 출력 | [% call-cta :: ... %] |

우선순위는 대시보드 임시 편집 > 토큰 > 사이트 공통 CSS > 엔진 기본값입니다.

## 개별 지정이 공통값보다 우선합니다

토큰에 적힌 항목은 사이트 공통 편집이 적용되지 않습니다. 사이트 공통 편집에서 해당 카드가 항목 아래에 표시되고, '개별 지정 해제하고 공통값 확인' 버튼으로 임시로 풀어서 볼 수 있습니다. 노션 원문은 바뀌지 않습니다.

카드 편집에서 '개별 지정'을 끄면 그 항목은 토큰에서 빠지고 공통값이나 기본값을 보여 줍니다.

## 표시 조건

- OVERLAY 항목(색·투명도, 방향, 시작, 끝)은 이미지가 배경이 되는 위/아래 배치 카드에서만 화면에 보입니다.
- IMAGE_RADIUS는 좌/우 배치 카드에서만 보입니다.
- BACKGROUND_MODE, BACKGROUND_COLOR는 이미지가 배경이 아닌 카드에서만 보입니다.
- 모바일 값(MIN_HEIGHT_MOBILE, PADDINGY_MOBILE, *_SIZE_MOBILE)은 창 폭이 768px 미만일 때만 화면에서 확인할 수 있습니다.
- 원본유지를 켠 항목은 값을 적용하지 않고 노션 원본을 그대로 둡니다. 원본유지가 기본으로 켜진 항목은 글자 크기, 굵기, 색, 배경색, 모바일 최소 높이입니다.

## 기능

- 되돌리기/다시 실행 (최대 100단계), 원본 복원, 눈 버튼(누르는 동안 시작 상태), 무효화, 항목별 ↺
- 임시저장 슬롯 (최대 30개, 자동으로 적용하지 않음), 스타일 프리셋
- 가져오기: 공통 :root CSS, 이 대시보드가 내보낸 JSON, call-cta 토큰
- 설정 검색, 다크/라이트, 최소화
- 페이지 클릭 선택: 켜 두면 콜아웃을 클릭해서 고르고 링크 이동을 막습니다.

시작 상태는 페이지를 처음 열었을 때, 즉 노션에 적힌 토큰과 공통 CSS가 반영된 상태입니다.

## 출력

- 사이트 공통 CSS: 엔진 기본값과 다른 값만 :root 블록으로 출력합니다. '전체 설정 출력'을 켜면 모든 항목을 출력합니다.
- 선택 카드 토큰: [% call-cta :: ... %]
- 변경한 카드 목록: 편집한 모든 카드를 '번호. 제목' 줄과 토큰으로 출력합니다. 같은 제목이 여러 개여도 번호로 구분합니다.
- 출력 키 이름은 정식 이름(PADDINGY)과 별칭(PADY) 중에서 고를 수 있습니다. 기본은 정식 이름입니다.
- 복사하기, 미니파이 복사(주석 제거)를 지원합니다.

## 가져오기

- 공통 :root CSS: --cta-*_Q2tq 변수를 검증 후 공통 편집으로 불러옵니다. 모르는 변수는 무시하고 알려 줍니다.
- 대시보드 JSON: 이전에 내보낸 전체 편집 상태를 불러옵니다.
- call-cta 토큰: 선택한 카드에만 채웁니다. '변경한 카드 목록'처럼 '번호. 제목' 줄이 붙은 여러 토큰을 붙여 넣으면 제목이 일치하는 토큰을 찾고, 같은 제목이 여러 개면 번호 순서로 짝을 맞춥니다. 일치하는 제목이 없으면 첫 번째 토큰을 씁니다.

## 설정 점검

시험값을 넣어 공통, 카드 편집이 엔진에 반영되는지 확인하고 원래대로 되돌립니다. 결과는 항목마다 '적용 / 개별 지정 우선 / 실패'로 표시됩니다. 개별 지정 우선은 정상 동작입니다. 눈에 보이는지는 직접 확인해야 합니다.

## 저장소 키

call-cta-dashboard-v1-preferences, call-cta-dashboard-v1-slots, call-cta-dashboard-v1-presets

## 알려진 제한

- 콜아웃 안의 제목, 본문, 이미지, 버튼 내용은 노션에서 수정합니다. 이 대시보드는 설정만 편집합니다.
- 노션 원문의 토큰은 엔진이 읽은 값 기준이므로, 노션에서 토큰을 고친 뒤에는 새로고침합니다.
- 노션이 화면을 다시 그려 카드가 바뀌면 목록의 다시 스캔 버튼을 누릅니다.
- 팝업이 차단되면 실행되지 않으며 PC 전용입니다.
- 가져오기의 토큰 읽기는 :: 구분자만 지원합니다.
- 실제 노션 화면에서의 동작은 직접 확인해야 합니다.
