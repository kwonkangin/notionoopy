# call-cta 

노션 콜아웃을 CTA(행동 유도) 영역으로 꾸미는 엔진입니다. 콜아웃 안의 제목, 본문, 버튼, 이미지는 그대로 쓰고 배치, 배경, 여백, 글자 스타일만 입힙니다.
 
## 필요한 것

- core.js v1.2.0 이상 (CoreEngine)
- 최신 브라우저 (Chrome 88 이상 등)

## 사용 방법

1. 노션에서 콜아웃을 만들고 제목, 본문, 버튼, 이미지를 넣은 뒤 콜아웃 안에 토큰 한 줄을 적습니다.

```
[% call-cta :: MIN_HEIGHT LG :: PADY 60 :: H1C #ffffff %]
```

2. 이미지를 텍스트 위/아래에 두면 박스 배경 이미지가 되고, 컬럼으로 나란히 두면 좌/우 배치가 됩니다.
3. 모든 콜아웃에 같은 값을 쓰려면 공통 CSS 변수(`:root`)로 지정합니다. 토큰에 적은 값이 공통 CSS보다 우선합니다.
4. 값은 call-cta-dashboard.js로 화면에서 조정한 뒤 출력된 CSS와 토큰을 복사해 붙여 넣으면 편합니다.

```css
:root {
  --cta-padding-y_Q2tq: 60px;
  --cta-h1-color_Q2tq: #ffffff;
}
```

## 우선순위

대시보드 임시 편집 > 토큰 > 공통 CSS 변수 > 엔진 기본값

아무 값도 정하지 않은 항목은 노션 원본 스타일을 그대로 유지합니다(원본유지).
