# Notion 탭 엔진 v15.1 — 사용 방법 

## 파일 구성

| 파일명 | 용도 |
|---|---|
| `tabs-engine.js` | GitHub에 올려서 Notion/Oopy 사이트에 불러오는 엔진 본체 |
| `tabs-engine.css` | GitHub에 올려서 엔진과 함께 불러오는 기본 CSS 변수 |
| `tabs-engine-option.css` | 각 CSS 변수의 기능·기본값·옵션을 설명하는 참고 문서 (필요 시 이 내용을 그대로 복사해 값만 바꿔 써도 됨) |
| `tabs-engine-dashboard.js` | 콘솔에서 실행하는 디자인 제어판 (팝업으로 뜸) |
| `tabs-engine-all.md` | 위 옵션 문서 + css + js 를 한 파일에 모아둔 통합 백업본 |
| `tabs-engine-howto.md` | 이 문서 |

---

## 1. 최초 설치 (사이트에 엔진 심기)

1. `tabs-engine.js` 와 `tabs-engine.css` 를 GitHub 저장소(공개 리포지토리)에 올립니다.
2. jsDelivr 등을 이용해 raw 링크를 CDN 링크로 바꿉니다.
   예: `https://cdn.jsdelivr.net/gh/사용자명/저장소명/tabs-engine.css`
3. Notion(Oopy 등 커스텀 도메인 서비스)의 Custom Code / Head 삽입 영역에 아래처럼 붙여넣습니다.

```html
<link rel="stylesheet" href="여기에_tabs-engine.css_CDN_링크">
<script src="여기에_tabs-engine.js_CDN_링크"></script>
```

4. 페이지에 있는 노션 탭 블록(`.notion-tab-block`)에 엔진이 자동으로 적용됩니다. 이 상태만으로도 `tabs-engine.css` 의 기본값대로 정상 작동합니다.

---

## 2. 디자인 조정 (대시보드 사용)

1. 디자인을 바꾸고 싶은 실제 페이지를 엽니다 (엔진이 이미 적용되어 있어야 함).
2. **이 사이트의 팝업 차단을 미리 허용**해 둡니다. (팝업이 처음 막혔다가 나중에 수동으로 허용하면 팝업이 창과 분리될 수 있으므로, 미리 허용하는 것을 권장합니다.)
3. 브라우저 개발자도구(F12) → Console 탭을 엽니다.
4. `tabs-engine-dashboard.js` 파일 내용 전체를 콘솔에 붙여넣고 실행합니다. (함수만 정의됨)
5. 아래 명령을 입력해 대시보드를 엽니다.

```js
notionTabLaunchDashboard_v15();
```

6. 팝업 제어판에서 슬라이더/색상/토글 등을 조정하면 **즉시 실제 페이지에 반영**됩니다.
7. 원하는 디자인이 완성되면 하단의 **"최종 적용 코드 출력하기"** 버튼을 누릅니다.
8. **복사하기** (또는 압축된 코드가 필요하면 **미니파이 복사**) 를 눌러 코드를 복사합니다.
9. 복사한 코드를 Notion 페이지의 Custom CSS / 코드 삽입 영역에 붙여넣습니다. (`tabs-engine.js`/`tabs-engine.css` 링크 **아래쪽**에 붙여넣어야 기본값을 덮어씁니다.)

출력되는 코드는 두 부분으로 구성됩니다.

- `<style> :root { ... } </style>` — 색상/여백/폰트 등 디자인 값
- `<script> ... </script>` — 탭이 넘칠 때 처리 방식(스크롤/줄바꿈/더보기/드롭다운) 설정

두 블록을 모두 붙여넣어야 디자인과 배치 방식이 전부 재현됩니다.

## 3. 대시보드 기능 안내

| 기능 | 설명 |
|---|---|
| 검색창 | "hover", "그림자", "여백", "글자", "배치" 등 키워드로 항목 필터링 |
| 🌙 다크 / ☀️ 라이트 | 대시보드 자체의 테마 전환 (실제 탭 디자인과는 무관) |
| 전체 초기화 | CSS 변수와 탭 배치 모드를 전부 최초 기본값으로 되돌림 |
| 💾 임시저장 (새 슬롯) | 현재 설정을 브라우저 localStorage 에 이름(시각)과 함께 저장 |
| 📂 저장 슬롯 목록 | 저장된 슬롯을 불러오거나 삭제 |
| 📥 가져오기 | 이전에 출력했던 코드를 붙여넣어 값을 그대로 복원 |
| ↺ 기본값 보기 (무효화) | 현재 미리보기 값을 지우고 사이트 원래 기본값으로 되돌림 (저장 슬롯은 유지) |
| 👁 기본값 잠깐보기 | 누르고 있는 동안만 기본값을 보여주고, 손을 떼면 현재 설정값으로 복귀 |
| 개별 항목 초기화(↺ 아이콘) | 각 항목만 따로 기본값으로 되돌림 |

## 4. 각 컨트롤 조작 방법

- **색상**: 왼쪽 색상칩 클릭 → 색 선택 / 가운데 슬라이더 → 투명도 / 오른쪽 코드란 → rgba·hex 직접 입력 (잘못된 형식 입력 시 빨간 테두리로 표시)
- **테두리 / 여백**: 상단 토글로 노출 여부 결정. 여백은 "개별조정" 토글을 켜면 위/오른쪽/아래/왼쪽을 각각 조정 가능
- **글자 크기 · 굵기**: 왼쪽 슬라이더가 크기, 오른쪽 슬라이더+드롭다운이 굵기 (100~900, 100단위)
- **hover 전환**: 왼쪽 슬라이더가 지속시간(0~1000ms), 오른쪽 드롭다운이 가속 곡선(easing)
- **탭 배치 모드**: 맨 위 노란 테두리 섹션에서 조정. 이 항목만 CSS가 아니라 자바스크립트 데이터 속성으로 적용됨

## 5. 문제가 생겼을 때

- **슬라이더가 안 움직여요** → v15.1 이후 프레임 단위로 값이 반영되도록 개선되어 있습니다. 여전히 느리면 페이지에 무거운 블록이 매우 많은 경우이니 새로고침 후 다시 시도하세요.
- **탭 모서리 둥글기가 안 바뀌어요** → `tabs-engine.js` 가 v15.1 이상인지 확인하세요. v15에서는 Notion 기본 CSS에 밀려 적용되지 않는 버그가 있었고, v15.1에서 수정되었습니다.
- **hover를 껐는데 뭔가 남아있어요** → `tabs-engine.js` 가 v15.1 이상인지 확인하세요. 같은 이유로 v15.1에서 완전히 수정되었습니다.
- **팝업이 안 열려요** → 브라우저 팝업 차단을 해제한 뒤 다시 `notionTabLaunchDashboard_v15();` 를 실행하세요.
- **콘솔에서 `notionTabLaunchDashboard_v15 is not defined` 오류** → 대시보드 파일 전체를 붙여넣지 않고 실행 명령만 입력한 경우입니다. 파일 전체를 먼저 붙여넣어 함수를 정의한 뒤 실행하세요.

## 6. 백업/복원 체크리스트

- 사이트에 실제로 걸려 있는 코드: `tabs-engine.js` + `tabs-engine.css` (GitHub) + Notion에 붙여넣은 대시보드 출력 코드(`:root` + `<script>`)
- 콘솔용 대시보드 도구: `tabs-engine-dashboard.js`
- 참고 문서: `tabs-engine-option.css`, `tabs-engine-all.md`, 이 문서

이 6개 파일을 모두 보관해두면, 사이트 디자인이 초기화되거나 엔진을 다른 사이트에 다시 설치해야 할 때 그대로 재사용할 수 있습니다.
