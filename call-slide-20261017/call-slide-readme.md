# call-slide-20261017

노션/우피 콜아웃을 가로 슬라이더로 만드는 call-slide 엔진과 설정 대시보드 배포본입니다.

## 구성

| 파일 | 설명 |
|---|---|
| call-slide.js | 엔진 v1.6.0 (대시보드 API 1.1.0) |
| call-slide-dashboard.js | 대시보드 v1.1.0 (콘솔 실행) |
| REFERENCE.md | 토큰·캡션·CSS 변수·API 요약 |
| DASHBOARD.md | 대시보드 사용 설명 |
| CHANGELOG.md | 변경 기록 |

## 로드 순서

1. core.js (v1.2.0 이상)
2. call-slide.js
3. call-card.js

call-slide를 call-card보다 먼저 로드해야 합니다. 순서가 바뀌면 콘솔에 경고가 나옵니다.
대시보드는 필요할 때만 PC 브라우저 콘솔에서 실행합니다. (팝업 허용)

## 빠른 시작

```text
상위 콜아웃  <- [% call-slide :: W 360px :: IMG BG %]
  하위 콜아웃 1
  하위 콜아웃 2
```

상위 콜아웃 바로 아래의 하위 콜아웃이 슬라이드가 됩니다. 자세한 내용은 각 파일 상단 주석을 참고하세요.

## 적용 후 확인

- `CallSlideEngine.version`이 `1.6.0`인지 확인합니다.
- 콘솔에 `[call-slide] ... 먼저 처리했습니다` 경고가 없는지 확인합니다.
- 링크 슬라이드 클릭, PC 마우스 드래그, 모바일 터치 드래그를 확인합니다.
- 대시보드에서 비율(BG)과 화면 끝까지 확장이 바로 반영되는지 확인합니다.
- 대시보드의 "새 창으로 미리보기"에서 이미지 모드 변경이 반영되는지 확인합니다.
