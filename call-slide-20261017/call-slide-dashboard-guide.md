# call-slide 대시보드
 
call-slide 슬라이더의 설정을 팝업에서 미리 보고 출력 코드를 만드는 콘솔용 도구입니다.

## 필요한 것

- call-slide.js v1.5.x 이상 (미리보기 창은 v1.6.0 이상)
- PC 브라우저, 팝업 허용

## 사용 방법

1. 페이지를 열고 콘솔에 `call-slide-dashboard.js` 전체를 붙여 넣어 실행합니다.
2. 편집 범위를 고릅니다. 사이트 공통은 :root CSS 변수, 선택 슬라이더는 토큰입니다.
3. 값을 바꾸면 화면에 바로 반영됩니다. 이미지 모드는 "미리보기 창"에서 확인합니다.
4. 최종적용 코드 출력하기로 CSS와 토큰을 복사해 노션에 붙여 넣습니다.

"새로고침"은 지금 보고 있는 공개 페이지 탭을 브라우저에서 새로 고치는 것입니다. 새로고침하면 임시 편집이 사라집니다.

## 토큰이 공통값보다 우선합니다

슬라이더에 토큰이 이미 적혀 있으면 사이트 공통 편집이 그 슬라이더에 적용되지 않습니다. 대시보드가 해당 슬라이더를 표시하고, "토큰 해제하고 공통값 확인" 버튼으로 임시로 풀어서 볼 수 있게 합니다. 노션 원문의 토큰은 바뀌지 않습니다.

## 편집 범위

| 범위 | 대상 | 출력 |
|---|---|---|
| 사이트 공통 | :root CSS 변수 | CSS 블록 |
| 선택 슬라이더 | 토큰 값 (개별 지정한 항목만) | `[% call-slide :: ... %]` |

## 미리보기 창과 설정 점검

- 새 창으로 미리보기: 같은 페이지를 새 창에서 다시 불러와 임시 설정을 적용합니다. 현재 창에는 영향이 없습니다.
- 설정 점검: 시험값을 넣어 모든 슬라이더에 값이 반영되는지 확인하고 원래대로 되돌립니다.

## 저장소 키

`ce-slide-dashboard-v1-preferences`, `ce-slide-dashboard-v1-slots`, `ce-slide-dashboard-v1-presets`, `ce-slide-preview-v1`

## 알려진 제한

- 슬라이드별 OL·URL 편집, 모바일 확인 창은 없습니다.
- 화살표 아이콘은 Font Awesome이 로드된 페이지에서만 모양이 바뀝니다.
