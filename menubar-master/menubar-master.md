# 에픽션 동적 내비게이션 및 마스터 제어판 안내서

본 문서는 우피 기반 웹사이트에 적용할 수 있는 반응형 내비게이션 엔진과 이를 시각적으로 조작할 수 있는 제어판의 사용 방법을 안내합니다.

## 핵심 기능

- 실시간 화면 제어: 콘솔에서 제어판을 실행하여 여백 색상 크기 등을 즉각적으로 조정하고 확인할 수 있습니다.
- 무제한 여백 확장: 기존의 간격 제한을 해제하여 화면이 허용하는 한 넓고 시원한 배치를 구현할 수 있습니다.
- 직관적인 색상 및 그림자 지정: 색상 추출기와 슬라이더를 결합하여 복잡한 코드 없이 그림자와 투명도를 조절합니다.
- 우피 검색 연동: 일반 요금제와 전문가 요금제의 검색 기능을 자동으로 파악하여 내비게이션 요소에 통합합니다.
- 반응형 모바일 최적화: 모바일 화면 전환 분기점을 직접 지정할 수 있으며 주요 행동 단추의 가로 세로 다단 배열을 지원합니다.
- 아이콘 자동 추출: 폰트어썸 태그 전체를 복사하여 붙여넣어도 필요한 클래스명만 자동으로 추출하여 적용합니다.

## 구성 요소

1. 내비게이션 코어 엔진: 웹사이트 상단 영역에 실제로 표시되는 뼈대와 서식 코드입니다.
2. 제어판 실행 스크립트: 관리자 화면에서 실행하여 엔진의 설정을 변경하는 자바스크립트 코드입니다.

## 적용 및 사용 방법

1. 웹사이트 삽입
제공받은 내비게이션 코어 엔진 코드를 우피 관리자 페이지의 HTML 편집 영역에 삽입하고 저장합니다.

2. 제어판 실행
웹사이트를 브라우저로 엽니다. 키보드 기능키 에프12를 눌러 개발자 도구를 열고 콘솔 탭으로 이동합니다. 제어판 실행 스크립트를 붙여넣고 엔터 키를 눌러 팝업창을 띄웁니다. 웹 브라우저의 팝업 차단이 설정되어 있다면 해제해야 합니다.

3. 디자인 및 데이터 수정
제어판 팝업창에서 대메뉴 추가 하위 메뉴 설정 주요 행동 단추 배치 등을 원하는 대로 수정합니다. 화면에 변경 사항이 즉시 나타납니다.

4. 변경 사항 최종 적용
모든 수정을 마친 후 제어판 하단의 코드 출력하기 단추를 누릅니다. 기본 복사 또는 압축 복사 단추를 눌러 코드를 복사한 뒤 우피 관리자 페이지의 가변 데이터 구역을 덮어쓰기하여 저장합니다.

## 설정 지원 항목

- 헤더 기본 배치: 배경색 전체 높이 최대 너비 좌우 여백 등
- 대메뉴 제어: 메뉴 정렬 위치 사이 간격 글자 크기 굵기 등
- 하위 메뉴 설정: 심플형 및 상세형 배경색 테두리 둥글기 그림자 효과 내부 여백 등
- 아이콘 및 텍스트: 전역 아이콘 색상 개별 아이콘 색상 크기 제목 및 설명글 서식 등
- 주요 행동 단추: 단추 간격 둥글기 테두리 두께 배경색 등
- 검색 기능: 피씨 및 모바일 검색 단추 디자인 위치 지정 등
- 모바일 화면 제어: 햄버거 단추 색상 화면 전환 시점 모바일 배열 등

## 주의 사항

- 코드를 복사하고 붙여넣을 때 기존 코드의 여는 태그와 닫는 태그가 훼손되지 않도록 주의하십시오.
- 제어판에서 전체 복구 단추를 누르면 저장하지 않은 모든 수정 사항이 최초 상태로 되돌아갑니다.
