# call-counter 대시보드

call-counter의 설정을 팝업에서 미리 보고 출력 코드를 만드는 콘솔용 도구입니다.

## 필요한 것

- call-counter.js v4.0.0 이상 (CallCounterEngine.dashboard API 1.0.0)
- PC 브라우저, 팝업 허용

## 사용 방법

1. 페이지를 열고 콘솔에 `call-counter-dashboard.js` 전체를 붙여 넣어 실행합니다.
2. 편집 범위를 고릅니다.
3. 값을 바꾸면 화면에 바로 반영됩니다.
4. 최종적용 코드 출력하기로 CSS, 카드 토큰, 마커를 복사해 노션에 붙여 넣습니다.

새로고침하면 임시 편집이 사라집니다.

## 편집 범위

| 범위 | 대상 | 출력 |
|---|---|---|
| 사이트 공통 | :root CSS 변수. 맨 위 "기본 모양"에서 숫자 기본 크기·굵기와 기본 정렬 설정 | CSS 블록 |
| 카드 | 콜아웃·컬럼 하나의 토큰 (개별 지정한 항목만) | `[% call-counter :: ... %]` |
| 마커 | 숫자 하나의 개별 설정 | `[# 접두 :: 숫자 :: 접미 :: @키 값 #]` |

우선순위는 마커(@) > 카드 토큰 > 바깥 토큰 > 사이트 공통 CSS > 엔진 기본값입니다.

## 개별 지정이 공통값보다 우선합니다

카드 토큰이나 마커의 @ 설정으로 지정된 항목은 사이트 공통 편집이 적용되지 않습니다. 사이트 공통 편집에서 해당 카드·마커가 표시되고, "개별 지정 해제하고 공통값 확인" 버튼으로 임시로 풀어서 볼 수 있습니다. 노션 원문은 바뀌지 않습니다.

## 설정 점검

시험값을 넣어 공통, 카드, 마커 편집이 모든 마커에 반영되는지 확인하고 원래대로 되돌립니다.

## 저장소 키

`call-counter-dashboard-v1-preferences`, `call-counter-dashboard-v1-slots`, `call-counter-dashboard-v1-presets`

## 알려진 제한

- 접두·접미의 글자와 마커 추가·삭제는 노션에서 수정합니다.
- 카운트업 관련 설정은 카드가 화면에 다시 들어올 때 확인됩니다.
- 실제 노션 화면에서의 동작은 직접 확인해야 합니다.
