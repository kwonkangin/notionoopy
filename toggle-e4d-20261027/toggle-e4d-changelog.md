# toggle-e4d 변경 이력

이 문서는 대화에서 제작한 배포 파일 기준입니다. GitHub 업로드 여부나 커밋 해시는 기록하지 않습니다.

## 엔진 v1.1.0 — 2026-10-27

- `--toggle-icon-stroke_e4d` 추가: thin / normal / bold.
- 모드 2 기본 선 굵기를 normal(48)로 지정. thin 32, bold 64.
- 모드 3은 thin 7, normal 10, bold 13. normal은 이전 꺾쇠 두께 유지.
- 모드 1·4는 굵기 옵션 제외.
- 모드 2를 둥근 끝 선 기반 SVG 마스크로 렌더링.
- 대시보드 schema 항목 수: 45개.
- 호버 기본값 0 유지.

### 검증 기록

모의 노션 구조를 넣은 Chromium에서 19개 항목 검사: 18개 통과, 이전 Font Awesome plus 기준과의 픽셀 겹침 비교 1개는 임의 기준 IoU 0.97에 미달(약 0.96). 이 결과는 육안 동일성이나 실제 폰트 렌더링 동일성을 보증하지 않습니다.

## 엔진 v1.0.0 — 2026-10-27

기존 toggle-master에서 독립 엔진으로 재구성했습니다.

- JS 단일 파일에서 CSS 생성. 별도 CSS·core.js·토큰 의존 제거.
- 코드명 toggle, 접미사 e4d, `--toggle-이름_e4d` 네이밍 적용.
- 전역 API `window.toggle_e4d` 및 대시보드 API 추가.
- 모드 2 외부 폰트 의존 제거. Font Awesome은 모드 4에서만 사용(비교 패널 예외).
- 실제 토글에만 표시를 달아 일반 문단·일반 버튼으로의 스타일 번짐과 아이콘 오탐 축소.
- 제목 토글의 박스 디자인 제외. 카드 외형은 카드 엔진에 맡김.
- 콜아웃 독립 제어 제거, 폰트 그룹은 기본 꺼짐으로 유지.
- 기본값: theme 1, hover 0, font 0.
- 색·투명도 통합, 단위 없는 숫자 보정, 기본값과 다른 CSS만 출력하는 API 추가.
- 중복 실행 가드와 DOM 변화 처리 추가.

### 검증 기록

모의 노션 구조의 Chromium 테스트 37개 항목 통과. 실제 Oopy 페이지의 전체 레이아웃·반응형 검증과는 별개입니다.

## 대시보드 v1.0.0 — 2026-10-27

- 콘솔 실행 → 690×980 팝업, Shadow DOM UI.
- 엔진 schema 기반 45개 설정 항목 생성.
- 사이트 공통 편집만 지원. 토큰·개별 토글 편집 없음.
- 엔진이 생성한 CSS를 사용하는 샘플 토글 미리보기.
- 모드 2·3에서만 선 굵기 조건 안내. 기본값 normal.
- 조건 미충족 항목 흐림 표시 및 이유 안내.
- 되돌리기/다시 실행, 원본 복원, 눈 버튼, 무효화, 항목별 편집 취소·기본값.
- 임시저장 슬롯 30개, 스타일 프리셋, 검색, 다크/라이트, 최소화.
- 기본값과 다른 설정만 출력. 전체 출력·style 태그 포함·미니파이 복사 옵션.
- 새 CSS·JSON·옛 --tg-* 가져오기, 폐기 변수 안내, 실패 시 복원.
- 엔진 상태 및 설정 점검.

### 검증 기록

Chromium 팝업 시나리오 46개 항목 통과. 설정 점검 결과 43개 적용, 2개 값 반영, 실패 0. 검사에는 대화의 엔진 v1.1.0과 같은 동작을 재구성한 테스트용 사본(compare 제외)을 사용했습니다. 실제 업로드된 엔진과 Oopy 화면 조합은 별도 확인이 필요합니다.
