# toggle-e4d 대시보드 사용 안내

대시보드 v1.0.0 / 엔진 v1.1.0 기준입니다.

## 1. 실행

1. toggle-e4d 엔진이 설치된 Oopy 페이지를 PC 브라우저로 엽니다.
2. 콘솔에서 `toggle_e4d.version`이 `1.1.0`인지 확인합니다.
3. `toggle-e4d-dashboard.js` 파일 전체를 콘솔에 붙여 넣어 실행합니다. script 태그를 붙이지 않습니다.
4. 팝업 차단 안내가 나오면 해당 사이트의 팝업을 허용한 뒤 다시 실행합니다.

이 도구는 노션 원문이나 GitHub 파일을 수정하지 않습니다. 실제 페이지에 임시 편집을 적용하며, 새로고침하면 사라집니다. 저장 슬롯과 프리셋은 브라우저에 별도로 남습니다.

## 2. 기본값

| 항목 | 기본 |
|---|---|
| 모드 | 3: 꺾쇠 회전 |
| 선 굵기 | normal: 보통. 모드 2는 48, 모드 3은 10 |
| 테마 | 1: 노션 순정 색 유지 |
| 호버 | 0: 꺼짐 |
| 폰트 커스텀 | 0: 노션 기본 서식 |

페이지에 이미 변수가 있으면 그 값을 읽습니다. 예를 들어 hover:1이 명시된 페이지에서는 대시보드에도 켜진 값이 보입니다. 기본값을 바꾼다고 기존 명시 값까지 자동 삭제되는 것은 아닙니다.

## 3. 미리보기와 편집

팝업 위쪽 미리보기는 일반 토글 닫힘·열림, 제목 토글 H1·H3, 일반 문단을 보여줍니다. 기호를 클릭하면 샘플을 여닫습니다. 실제 페이지의 토글 개폐 상태를 바꾸는 기능은 아닙니다.

설정 변경은 샘플과 실제 페이지에 함께 적용됩니다. 샘플은 단순화한 구조라 실제 노션 배치를 완전히 재현하지는 않습니다. 특히 카드 엔진 안의 여백과 글자 정렬은 실제 페이지에서 확인하세요.

### 설정 그룹

1. 토글 기호: 모드, 자동/수동 크기, 반전, 선 굵기, 기호 색, Font Awesome 클래스.
2. 배치와 정렬: 좌우 배치, 상하 정렬, 글자 정렬.
3. 여백: padx, pady, gap.
4. 색 테마와 박스: 테마, 글자색, 배경색, 모서리, 테두리.
5. 마우스 올림: 호버 켜기, 속도, 호버 색.
6. 폰트 서식: 기본 접힘. font를 켠 경우 제목·본문 크기/굵기/색 적용.

조건이 맞지 않는 항목은 흐리게 보입니다. 잠긴 것은 아니므로 미리 값을 입력할 수 있습니다. 선 굵기는 모드 2·3에서만 효과가 있고 모드 4에서는 무시됩니다.

### 색과 투명도

- 색 선택기, HEX 직접 입력, 투명도 슬라이더를 제공합니다.
- 투명도는 HEX 끝의 알파로 합쳐 출력됩니다. 예: 빨강 50%는 `#ff000080`.
- 직접 입력은 rgb() 등의 유효한 CSS 색도 받습니다. HEX가 아닌 입력에서는 투명도 슬라이더를 사용할 수 없는 경우가 있습니다.
- 기호 색의 '비움'은 글자색을 따른다는 뜻입니다. 투명하게 만들려면 transparent를 입력합니다.

### 항목 버튼

- ↺: 그 항목의 임시 편집을 취소하고 페이지 값 또는 엔진 기본값으로 돌아갑니다.
- 기본값: 페이지에 값이 있더라도 현재 항목을 엔진 기본값으로 임시 지정합니다.
- 출처: 임시 편집, 노션 변수, 엔진 기본값 중 어디에서 읽었는지 보여줍니다.

## 4. 상단 도구

| 도구 | 동작 |
|---|---|
| ↶ / ↷ | 되돌리기 / 다시 실행. 최대 100단계. 연속 입력은 묶일 수 있습니다. |
| 원본 복원 | 임시 편집을 모두 지웁니다. 되돌리기로 다시 가져올 수 있습니다. |
| 눈 | 누르는 동안 시작 상태를 보고 떼면 편집 상태로 돌아갑니다. |
| 무효화 | 임시 편집과 되돌리기 기록을 모두 지웁니다. 슬롯·프리셋은 유지합니다. |
| 임시저장 | 현재 임시 편집을 슬롯에 저장합니다. 최대 30개. |
| 불러오기 / 삭제 | 선택한 슬롯을 불러오거나 삭제합니다. |
| 다크/라이트 | 팝업 UI 테마 변경. 사이트 디자인에는 영향이 없습니다. |
| 최소화 | 팝업 안의 UI를 접습니다. 다시 열기 버튼으로 복귀합니다. |
| × | 대시보드를 닫습니다. 이미 적용한 임시 편집을 자동 취소하는 버튼은 아닙니다. |

원본으로 돌아간 뒤 닫으려면 먼저 원본 복원을 누르세요. 새로고침해도 임시 편집은 사라집니다.

프리셋은 현재 설정 전체를 저장합니다. 임시저장 슬롯은 임시 편집만 저장합니다. 어느 쪽도 실행 시 자동 적용하지 않습니다.

## 5. 최종 코드 출력

1. 최종적용 코드 출력하기를 누릅니다.
2. 기본은 엔진 기본값과 다른 유효 설정만 출력합니다.
3. 전체 설정 출력은 필요할 때만 켭니다.
4. 노션에 HTML을 붙여 넣는 경우 style 태그 포함을 켤 수 있습니다.
5. 복사하기 또는 미니파이 복사를 누릅니다.
6. 노션의 기존 변수 블록을 통째로 교체합니다. 새 블록을 계속 추가하지 마세요.
7. 저장 후 Oopy 페이지를 새로고침해 같은 모습인지 확인합니다.

예: 모드 2와 오른쪽 배치만 기본값과 다르면 다음과 같습니다.

```html
<style>:root{--toggle-mode_e4d:2;--toggle-icon-side_e4d:right}</style>
```

선 굵기 보통, 테마 순정, 호버 꺼짐, 폰트 기본은 출력하지 않아도 됩니다.

'변경값만'은 이번 세션에 만진 항목만을 뜻하지 않습니다. 페이지에 원래 있던 유효 설정도 엔진 기본값과 다르면 출력합니다. 비활성 조건의 설정도 기본값과 다르면 보존해 출력할 수 있습니다.

## 6. 가져오기·백업

가져오기 칸에 아래 중 하나를 붙여 넣고 검증 후 가져오기를 누릅니다.

- 새 `--toggle-이름_e4d` CSS. style 태그 포함도 가능.
- 예전 `--tg-*` 변수 블록.
- 전체 편집 JSON 내보내기로 만든 JSON.

불러오기 전에 임시 편집 초기화를 켜면 기존 임시 편집을 지우고 불러옵니다. 잘못된 값이 있으면 이전 편집 상태로 복원합니다.

### 옛 변수 변환

- row-reverse → icon-side:right, flex-start → icon-valign:top.
- scaleX(-1) → icon-flip:x 등.
- 크기·둥글기 단위 보정은 엔진에 맡깁니다.
- 색과 별도 opacity를 하나의 HEX 알파 값으로 합칩니다(지원 가능한 HEX 입력).
- co-*와 개별 use-h1 등의 폐기 변수는 무시했다고 안내합니다.
- 빈 fa-closed/fa-opened는 기본값을 사용하도록 생략합니다.

주의: 옛 블록에 use-hover:1이 있으면 변환 후에도 hover:1로 가져옵니다. 호버를 끄려면 해당 스위치를 끄거나 기본값을 누르세요.

## 7. 설정 점검·엔진 상태

설정 점검은 각 항목에 시험값을 적용하고 CSS 또는 아이콘 요소가 바뀌는지 확인합니다. 필요한 조건은 임시로 맞추고 종료 후 이전 편집을 복원합니다.

- 적용: 값이 반영되고 생성 CSS가 바뀜.
- 값 반영: 클래스 설정 등 값이 반영됨. 시각 결과는 직접 확인해야 함.
- 실패: 값·CSS·요소 확인에 실패. 결과와 콘솔 오류를 기록하세요.

검사는 사이트 디자인의 모든 충돌을 증명하거나 배제하지 않습니다. 실행 중 페이지 모습이 잠깐 바뀔 수 있습니다.

엔진 상태에는 버전, 토글 수, 열림 수, Font Awesome 요소 수, 옛 코드 잔존 경고를 표시합니다. 다시 스캔으로 현재 DOM의 토글을 재탐색할 수 있습니다.

## 8. 저장·문제 해결

저장소 키:

- toggle-e4d-dashboard-v1-preferences
- toggle-e4d-dashboard-v1-slots
- toggle-e4d-dashboard-v1-presets

동일 브라우저·사이트 origin의 localStorage를 사용합니다. 저장 공간 제한·브라우저 데이터 삭제·시크릿 모드 등에 영향을 받습니다. 중요한 설정은 CSS나 JSON으로 별도 복사하세요.

| 증상 | 확인 |
|---|---|
| 팝업이 안 열림 | 팝업 허용, 엔진 API와 버전 확인 |
| 기본값인데 호버 색이 바뀜 | 페이지 변수에 hover:1이 남았는지, 옛 CSS나 바깥 카드 호버인지 확인 |
| 굵기 옵션이 흐림 | 모드 2·3인지 확인 |
| 모드 4 아이콘이 비어 있음 | Font Awesome 클래스, CDN·폰트 요청 차단 확인 |
| 화면에서 일부 설정이 안 보임 | 적용 조건, 토글 종류, 다른 엔진의 스타일 확인 |
| 새 엔진을 붙여도 구버전 | 중복 스크립트 제거 후 새로고침, 고정 커밋 링크 확인 |

오류 보고 시 엔진·대시보드 버전, `toggle_e4d.diagnose()` 결과, 설정 점검 결과, 실제 화면을 함께 기록하세요.
