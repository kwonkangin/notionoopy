# gallery-overlay 대시보드

gallery-overlay의 설정을 팝업에서 미리 보고 출력 코드를 만드는 콘솔용 도구입니다.

## 필요한 것

- gallery-overlay-engine.js / .css v2.1.0 권장 (v2.0.0 이상, dashboard API 1.0.0). 2.0.x는 일부 항목이 없고, 2.0.0 미만에서는 실행되지 않습니다.
- PC 브라우저, 팝업 허용

## 사용 방법

1. 대시보드를 쓸 페이지를 엽니다. 엔진이 적용된 공개 페이지여야 합니다.
2. 개발자 도구 콘솔에 `gallery-overlay-dashboard.js` 전체를 붙여 넣어 실행합니다. `<script>` 태그는 넣지 않습니다.
3. 편집 범위(사이트 공통 / 갤러리 / 속성 스키마)를 고르고 값을 바꾸면 페이지에 바로 반영됩니다.
4. 맨 아래 "최종적용 코드 출력하기"를 눌러 나온 코드를 사이트의 설정 블록과 교체합니다.

변경은 현재 페이지의 임시 미리보기이며 노션과 GitHub에는 아무것도 쓰지 않습니다. 대시보드를 닫아도 편집은 남고, 페이지를 새로고침하면 사라집니다.

## 편집 범위

| 범위 | 대상 | 출력 |
|---|---|---|
| 사이트 공통 | `:root` CSS 변수 106개 (14개 섹션) | `<style>` 블록 |
| 갤러리 | `GA_GALLERY_TARGETS`의 키워드 행 (키워드, 디자인, 제목·탭·썸네일 설정) | `window.GA_GALLERY_TARGETS` |
| 속성 스키마 | `GA_PROP_SCHEMA` (JSON 편집) | `window.GA_PROP_SCHEMA` |

사이트 공통의 "개별 설정" 스위치는 특정 갤러리 하나를 지정하는 것이 아니라 커버형과 사이드형의 값을 따로 정하는 기능입니다. 켜면 커버형(`--ga-*`)과 사이드형(`--ga-side-*`) 값을 각각 입력합니다. 같은 디자인의 갤러리끼리 서로 다른 값을 주는 기능은 없습니다.

## 항목별 동작

- 선택 항목은 엔진이 알려 주는 한글 이름표로 표시됩니다.
- 항목마다 ↺ 버튼이 있고, 그 항목만 대시보드를 연 시점의 상태로 되돌립니다.
- 색 항목은 "비움"을 지원합니다. 비우면 일반 속성 서식을 따릅니다.
- 칩 높이는 "자동(auto)" 스위치를 켜면 입력이 잠기고 `auto`가 적용됩니다. 고정 높이가 상하 여백 × 2 + 16px보다 낮으면 경고가 표시됩니다.
- 그림자는 프리셋(없음, 약하게, 보통, 강하게)으로 켜기, 위치, 흐림, 색을 한 번에 바꿉니다.
- 검색창에서 이름, 키, CSS 변수로 항목을 찾습니다.

## 주요 기능

- 되돌리기 / 다시 실행: 최대 100단계
- 원본 복원: 현재 범위(사이트 공통, 선택 갤러리, 속성 스키마)만 대시보드를 연 시점으로 되돌립니다.
- 눈 버튼(◉): 누르는 동안 시작 상태를 보여 주고, 떼면 편집 상태로 돌아옵니다.
- 무효화: 임시 편집 전체를 시작 상태로 되돌립니다. 저장 슬롯은 유지합니다.
- 전체 기본값: 공통 설정을 엔진 문서 기본값으로 바꿉니다. 갤러리와 속성 스키마는 유지합니다.
- 임시저장 슬롯: 공통, 갤러리, 스키마 편집을 함께 저장합니다. 최대 30개이며 자동으로 적용하지 않습니다.
- 스타일 프리셋: 사이트 공통은 현재 값 전체, 갤러리는 선택 행, 속성 스키마는 배열을 저장합니다.
- 페이지 클릭 선택: 갤러리 모드에서 켜면 페이지의 카드를 클릭해 소속 갤러리를 고릅니다. 링크 이동은 막힙니다.
- 가져오기: `:root` CSS, 이 대시보드가 출력한 JSON, 통합 설정 코드를 검증 후 불러옵니다. 알 수 없는 CSS 변수는 건너뛰고 알려 주며, 값이 하나라도 올바르지 않으면 전체를 적용하지 않습니다.
- 다크 / 라이트, 최소화(⚙ 버튼으로 다시 엶)

## 설정 점검 / 카드 매핑

- 카드 매핑 점검: 각 카드의 실제 줄 타입 순서와 스키마 매칭 결과(`ok`, `ambiguous`, `unmatched`, `noschema`), 배정된 속성 이름을 표로 보여 줍니다. 엔진이 낸 경고도 함께 표시합니다. 읽기 전용입니다.
- API 임시값 반영 점검: 카드 모서리 둥글기를 잠시 47px로 바꿔 엔진이 값을 반영하는지 확인하고 원래대로 되돌립니다.

두 점검 모두 엔진이 값을 받았는지 확인하는 것이며, 화면 배치가 의도대로인지는 직접 확인해야 합니다.

## 출력 코드

- 기본 출력은 현재 사이트에 명시된 변수와 임시 편집값만 포함합니다. BEST 태그 변수와 그림자 켜기는 항상 포함됩니다.
- "전체 설정 출력"을 켜면 엔진 문서 기본값까지 모두 출력합니다.
- 키워드와 속성 스키마는 전체 배열로 출력됩니다. 속성 번호와 구역 배치(`--ga-section-*`)는 스키마 순서와 맞아야 합니다.
- 복사하기와 미니파이 복사(주석·공백 제거)를 지원합니다.

## 저장소 키

`gallery-dashboard-v1-preferences`, `gallery-dashboard-v1-slots`, `gallery-dashboard-v1-presets`

같은 브라우저, 같은 사이트 주소에서만 보입니다. v1.0.0에서 만든 슬롯, 프리셋, 내보낸 JSON은 v1.0.1에서도 그대로 불러옵니다.

## 사용하는 엔진 API

`dashboard.schema`, `common.read / overrides / apply / restore`, `galleries.list / targets / setTargets`, `properties.read / apply / restore / audit`, `cards.galleryOf`, `rescan`, `forceSync`, `warnings`

필수 API가 없거나 엔진 버전이 2.0.0 미만이면 실행하지 않고 콘솔에 오류를 남깁니다.

## 알려진 제한

- PC 전용이며 팝업이 차단되면 실행되지 않습니다.
- 라이브 페이지만 미리 봅니다. 태블릿·모바일 값은 실제 페이지를 해당 폭으로 줄여야 확인되고, 팝업 폭과는 무관합니다.
- 같은 디자인의 갤러리별 스타일 덮어쓰기는 없습니다.
- 노션 원문과 사이트 설정 블록을 자동으로 고치지 않습니다. 출력 코드를 직접 붙여 넣어야 합니다.
- `--ga-side-thumb-top-fit`은 엔진 CSS에 쓰는 규칙이 없어 바꿔도 화면이 달라지지 않습니다.
- 실제 노션·우피 화면의 최종 모습은 직접 확인해야 합니다.
