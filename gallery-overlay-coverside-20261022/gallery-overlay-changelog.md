# 변경 기록

## 2026-10-22 (2차) 엔진 2.3.0 / 대시보드 1.2.0

JS와 CSS는 같은 버전(2.3.0)을 함께 올립니다. CSS 2.2.0 이상은 `html[data-ga-bp]` 속성을 기준으로 태블릿·모바일 규칙을 적용하므로 2.2.0 미만 JS와 함께 쓰면 태블릿·모바일 규칙이 적용되지 않습니다.

- gallery-overlay-engine.js / .css v2.3.0
  - 줄 수 제한(말줄임표): 제목 `--ga-title-lines`, 텍스트 속성 `--ga-text-lines`, 속성 번호별 `--ga-prop-lines: "2=1 5=3"`. 각각 `-tab`, `-mob` 변수로 폭별 설정. 비어 있으면 태블릿은 PC 값을, 모바일은 태블릿 값(없으면 PC 값)을 따르고 속성별 목록은 번호 단위로 덮어씀. 0이면 제한 없음. 선택·다중선택(칩) 속성은 대상이 아님
  - 줄 수 기본값: 제목 2줄, 텍스트 속성 2줄 (커버형과 사이드형 모두)
  - 실제로 잘린 글에만 전체 글 툴팁(title) 부착. 잘리지 않으면 붙지 않음
  - 같은 줄 카드 높이 맞춤 `--ga-side-row-equal` (기본 1): 사이드형·스택형에서 같은 줄 카드를 가장 큰 카드 높이에 맞춤. 열 수나 폭이 바뀌면 다시 계산
- gallery-overlay-dashboard.js v1.2.0
  - 엔진 2.3.0 항목 대응: "줄 수 제한(말줄임표)" 그룹, 같은 줄 카드 높이 항목. 속성별 줄 수 형식 검증(`2=1 5=3`)

## 2026-10-22 (1차) 엔진 2.2.0 / 대시보드 1.1.0

- gallery-overlay-engine.js / .css v2.2.0
  - 기본값 표 `GA_DEFAULTS`: 엔진이 시작할 때 `<style id="ga-defaults">`로 `<head>` 맨 앞에 주입. 사이트 설정 블록에는 기본값과 다른 변수만 적으면 됨. 기본값은 JS 맨 위 표 한 곳에서만 관리
  - 스택형 `design: "stack"`: 썸네일 위·글 아래 세로 카드. 전용 변수 `--ga-stack-*` (PC 3열, 태블릿 2열, 모바일 1열 고정, 썸네일 비율 4/3, 크롭 위치, 모서리, 가득 채우기, 이미지 없는 카드). 글 영역은 사이드형(`--ga-side-*`) 변수를 읽음. BEST 태그는 썸네일 오른쪽 위에 얹음
  - 썸네일 가득 채우기 `--ga-side-thumb-bleed` / `-tab` / `-mob`: 좌·우 배치는 위·아래·바깥쪽, 위·아래 배치는 위·좌·우가 카드 테두리까지 닿음. 비어 있으면 PC 값을 따름
  - 위·아래 배치 썸네일을 고정 가로세로비 `--ga-side-thumb-top-ratio`(기본 4/3)로 잘라 채우고, 최대 높이 `--ga-side-thumb-top-max-height`(기본 360px, `none`이면 제한 없음)를 둠. 위쪽과 아래쪽 모두 엔진이 만든 복제 이미지로 그림
  - 기준 폭 변수 `--ga-bp-mob`(기본 600px)와 `--ga-bp-tab`(기본 1024px). JS가 `html[data-ga-bp]`(pc, tab, mob)를 붙이고 CSS의 미디어 쿼리를 모두 이 속성 기준으로 교체. 모바일 기준이 768px에서 600px로 바뀌어 아이패드 미니 세로(744px)가 태블릿 구간이 됨
  - 라벨 글자색, 관계형 글자색, 날짜 글자 굵기는 기본값 표에서 비움. 라벨 글자색은 본문 글자색을 상속하고, 관계형 글자색은 칩 글자색을 따름
  - 커버형의 태블릿·모바일 자동 축소(카드 여백 12px/10px, 섹션 간격, 제목·칩 글자 크기)를 제거. 기본값 표가 항상 값을 주므로 사이트 설정과 충돌하기 때문
  - `GA_GALLERY_TARGETS` 항목에 `blockId`를 적으면 제목·탭 글자 대신 블록 ID로 갤러리를 지정 (선택 기능)
  - 대시보드 API: `defaults()`, `defaultOf(변수)` 추가. `common.css()`는 기본값 표와 다른 값만 출력 (`{ vsLoad: true }`면 예전처럼 열었을 때 값과 비교)
- gallery-overlay-dashboard.js v1.1.0
  - 설정 코드 출력이 기본값 표와 다른 값만 내보냄 ("전체 설정 출력" 스위치는 그대로 전체 출력). 출력 글자 수 표시
  - 갤러리 디자인에 스택형 추가, "스택형" 설정 그룹, 썸네일 가득 채우기·위/아래 비율·최대 높이(`none` 입력), 기준 폭 항목
  - 엔진이 2.3.0 미만이면 기능 부족 경고

### 2.1.x에서 올릴 때 달라지는 점

| 구분 | 이전 | 지금 | 대응 |
|---|---|---|---|
| 변수를 적지 않은 항목 | CSS·JS 폴백 값(14px 등)이 달랐음 | 기본값 표의 값 | 일부만 적은 페이지는 모양이 바뀜. 대시보드로 열어 "변경분만 출력"을 받아 설정 블록을 교체 |
| 제목·텍스트 속성 줄 수 | 제한 없음 | 기본 2줄 | 끄려면 `--ga-title-lines: 0; --ga-text-lines: 0;` (사이드형은 `--ga-side-*`) |
| 모바일 기준 폭 | 768px 이하 | 600px 이하 (601~1024px는 태블릿) | 예전 기준이 필요하면 `--ga-bp-mob: 768px;` |
| 태블릿 썸네일 위치 | 사이트 설정 값 | 기본 오른쪽(PC와 같은 모양) | 위쪽을 원하면 `--ga-side-thumb-side-tab: top;` |
| 모바일 썸네일 | 사이트 설정 값 | 기본 위쪽 + 카드 테두리까지 가득 + 4/3 | 여백 안쪽은 `--ga-side-thumb-bleed-mob: 0;` |
| 위·아래 배치 썸네일 | 원본 비율 | 고정 비율 4/3로 잘라 채움, 최대 높이 360px | `--ga-side-thumb-top-ratio`, `--ga-side-thumb-top-max-height` (원본 비율을 그대로 보이는 옵션은 없음) |
| 같은 줄 카드 높이 | 제각각 | 사이드형·스택형은 같은 줄에서 맞춤 | 끄려면 `--ga-side-row-equal: 0;` |
| 커버형 태블릿·모바일 자동 축소 | 있음 | 없음 | 필요하면 `--ga-card-padding` 등을 직접 설정 |
| 라벨·관계형 글자색 | 라벨 기본 `#ffffff` | 비움(본문 색 상속, 칩 글자색을 따름) | 필요하면 직접 지정 |
| 대시보드 출력 | 사이트에 적힌 값 전부 | 기본값과 다른 값만 | 전체가 필요하면 "전체 설정 출력" 스위치 |
